# MyHR — 발표 슬라이드 10장 + 데모 60초

형식(OT 기준): 제목 5초 + 본문 9장 **각 15초 자동 전환** + 데모 영상 60초 ≈ 3분 20초. 이후 Q&A 2분 ([PITCH.md](PITCH.md)).
실물 덱:
- HTML(자동 15초): [`public/pitch.html`](../public/pitch.html) — `←` `→` 이동, `Space` 일시정지, `S` 대사, `F` 전체화면
- Google 슬라이드: https://docs.google.com/presentation/d/1aivEBddEJFAcNSltYvbBCuwDYniBrAkzL7kbP3z-OCI/edit — 공유를 **"링크 있는 모든 사용자"** 로 설정
- PPTX 원본(임포트용): [`docs/MyHR-Trainthon-pitch.pptx`](MyHR-Trainthon-pitch.pptx) → Google 슬라이드에서 **파일 → 슬라이드 가져오기**

제출용 발표 링크 = Google 슬라이드 URL (공유 권한 확인).

규칙: **장당 메시지 하나, 대사 두 문장(60자 안팎).** 15초에 그 이상은 못 읽는다. 화면 글자는 대사가 아니라 헤드라인만.

심사 4축 매핑: 문제·가치 = 1~3·8 / 제품 완성도 = 4·7 + 데모 / AI 활용도 = 4~6 + 데모 / 사업화 = 9.

## 0. 제목 (5초)

**화면:** MyHR — 당신 네트워크의 인사팀 · 정승현 · 연세대 나노과학공학과
**대사:** "MyHR, 당신 네트워크의 인사팀입니다."

## 1. 문제 — 재회 직전 5초

**화면:** 카톡 알림 하나 크게. 「김재희: 형 오랜만이에요!」 아래에 물음표. 
**헤드라인:** 이 사람, 누구였지?
**대사:** "사람은 많이 만나는데 기억은 못 따라갑니다. 연락처엔 이름과 번호만 남고, 어디서 만났는지·근황·누구 소개였는지는 사라집니다."

## 2. 타겟 — 인맥이 빨리 느는 사람

**화면:** 동아리 → 학회 → 해커톤 → 인턴 아이콘 흐름. 아래 작게 「이 방에 있는 40명 전부」.
**헤드라인:** 소개·행사·커뮤니티를 넘나드는 사람
**대사:** "창업 동아리, 학회, 해커톤. 한 학기에 백 명씩 스치는 사람들입니다. 오늘 이 방이 첫 사용자입니다."

## 3. 솔루션 — 평범한 연락처, 딱 하나 다르다

**화면:** 앱 홈 스크린샷(390px 폰 프레임). 검색창에 「매운거 잘 먹음」, 결과에 사람 3명 + 근거 한 줄.
**헤드라인:** 맥락이 검색되는 연락처
**대사:** "앱을 열면 그냥 연락처 목록입니다. 딱 하나 다릅니다. 이름이 아니라 '매운 거 잘 먹는 사람'으로 검색이 됩니다."

## 4. 핵심기능 ① — 입력: 캡처를 붙이면 끝

**화면:** 좌 카톡 그룹방 캡처 → 우 스와이프 카드 3장 (이름 + 추출된 사실 줄). 「Ctrl+V」 키캡.
**헤드라인:** 폼 없음. 캡처가 입력이다
**대사:** "카톡 캡처를 붙이면 AI가 누가 무슨 말을 했는지 읽어 사실 한 줄씩 뽑습니다. 사람 카드를 오른쪽으로 넘기면 저장. 스샷은 폐기됩니다."

## 5. 핵심기능 ② — 저장: 스키마를 AI가 키운다

**화면:** 표 하나. `attributes (person, key, value, source)` 4컬럼, 행 3개: `works_at 핀테크` / `likes_spicy true` / `plays_soccer true`. 오른쪽에 「ALTER TABLE 없음. INSERT 한 줄」.
**헤드라인:** 사람을 저장하지 않는다. 문장을 저장한다
**대사:** "사람 표가 아니라 사실 한 줄 표입니다. '재희가 축구한다'가 세상에 처음 등장해도 컬럼 추가 없이 INSERT 한 줄. AI가 키 목록을 재사용해 키웁니다."

## 6. 핵심기능 ② 계속 — 표는 한 번도 안 바뀐다

**화면:** 세로 타임라인 4칸, 각 칸 = 메모 한 줄 → INSERT 한 줄. 표 헤더(4컬럼)는 위에 고정.
- 9/9 「재희 핀테크 다님」 → `재희 · works_at · 핀테크`
- 9/12 「재희 매운거 좋아함」 → `재희 · likes_spicy · true`
- 9/20 「재희랑 풋살 뛰었다」 → `재희 · plays_soccer · true` ← **세상 첫 등장. 컬럼 추가 없음**
- 9/25 「민수도 축구 함」 → `민수 · plays_soccer · true` ← **키 재사용**
**헤드라인:** 메모가 쌓일수록 스키마가 자란다
**대사:** "재희 메모 세 줄, 민수 메모 한 줄. 표는 한 번도 안 바뀌었는데 '축구'라는 개념이 생기고 두 사람에게 붙었습니다. 그래서 다음 화면의 질문이 가능해집니다."

## 7. 핵심기능 ③ — 질의: 네트워크에 묻기

**화면:** FAB 질문 시트. 「이번 주말 축구 할 사람 11명 뽑아줘」→ 11명 칩 + 각자 근거. 하단 작게 `WHERE key='plays_soccer' AND value='true'`.
**헤드라인:** "주말 축구 11명" → 명단
**대사:** "'주말 축구 할 사람 11명'이라고 물으면 명단과 근거가 나옵니다. 이건 SQL 한 줄입니다. AI는 입력을 읽을 때와 답을 말할 때, 양 끝에만 씁니다."

## 8. 일상 — 검색이 바꾸는 순간들

**화면:** 세로 3장면. 각 칸 = 상황 한 줄 + 검색어 칩.
- 행사장에서 마주침 → 「지난번에 소개받은 반도체 쪽」
- 주말에 사람 모을 때 → 「축구 할 사람 11명」
- 밥 약속 잡기 전 → 「매운거 잘 먹는 사람」
**헤드라인:** 이름이 생각 안 나도, 관계는 찾을 수 있다
**대사:** "행사장에서 마주쳤을 때, 주말에 사람을 모을 때, 밥 약속 잡기 전. 이름이 안 떠올라도 '반도체 쪽', '축구', '매운거'로 바로 찾습니다. 그게 매일 쓰는 이유입니다."

## 9. 사업화 — 웨지에서 레이어로

**화면:** 왼쪽 웨지(대학 창업 동아리·학회·해커톤) → 오른쪽 확장(영업·PR·VC·창업가·취준생). 하단: 무료 50명 / Pro ₩9,900·월.
**헤드라인:** 모든 프로페셔널의 인간관계 기억 레이어
**대사:** "대학 창업 커뮤니티에서 시작해 영업·VC·창업가로 갑니다. 50명까지 무료, 그 위는 월 9,900원. 목표는 모든 프로페셔널의 관계 기억 레이어입니다. 이제 데모입니다."

## 데모 영상 60초 (유튜브 일부공개)

화면 녹화만. 무대 캡처는 **시드와 이름 안 겹치는 새 사람 3장.** 프리셋 칩만 누르고 타이핑 안 함. 시드 리셋 후 녹화.

| 초 | 화면 | 자막/대사 |
| --- | --- | --- |
| 0–8 | 홈. 스크롤 한 번. 800명 목록 | "평범한 연락처. 800명 중 맥락이 있는 건 30명." |
| 8–20 | 검색 「매운거 잘 먹음」 → 3명 + 근거 | "이건 연락처 앱에서 안 됩니다." |
| 20–40 | FAB 정보 추가 → 카톡 캡처 Ctrl+V → 카드 3장 스와이프 → 목록에 행 생김 | "캡처 한 장. 사람 셋. 사실 줄로 저장." |
| 40–55 | FAB 질문 칩 「주말 축구 11명」 → 명단 + 근거 | "명단이 나옵니다. SQL 한 줄." |
| 55–60 | 상세 → 공통 지인 (또는 그래프 토글) | "당신 네트워크의 인사팀, MyHR." |

빌드가 4단계([PRODUCT.md](PRODUCT.md) §10)까지 안 가면 40–55 구간을 「검색 두 번째 예시」로 바꾸고, 슬라이드 7 헤드라인을 「매운거 잘 먹는 사람」으로 교체.
